# StudyFlow — Student Task Management Website

A responsive student productivity web application built with HTML, CSS and JavaScript.

## Features
- Add, edit, delete and complete tasks
- Subject and priority categorization
- Due-date and overdue tracking
- Search and task filters
- Dashboard statistics
- Local Storage persistence
- Dark mode
- Responsive mobile/desktop UI

## Run
Open `index.html` in a browser, or use VS Code Live Server.
